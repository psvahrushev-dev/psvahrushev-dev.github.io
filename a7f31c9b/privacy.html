Политика конфиденциальности

Приложение «tender». Редакция от 30 октября 2026 г.

1. Что это за приложение

«tender» — служебное приложение для внутреннего документооборота. Оно не распространяется публично, не предлагается третьим лицам и работает от имени одного корпоративного Google-аккаунта, которым распоряжается его владелец (далее — Владелец). Пользователей, кроме Владельца, у приложения нет.

2. Какие данные обрабатываются

Приложение обращается только к Google Диску того аккаунта, который выдал ему доступ. Оно запрашивает область https://www.googleapis.com/auth/drive. Такой доступ необходим, потому что приложение работает с папками, созданными людьми задолго до его появления: оно обязано найти существующую папку организации, года и месяца, а не только те объекты, которые создало само.

Используя этот доступ, приложение:

  • находит существующие папки по их наименованиям и создаёт недостающие папки года, месяца и конкретной закупки;
  • загружает в созданную папку файлы документации, полученные из корпоративной CRM-системы Владельца;
  • проверяет, не загружен ли такой файл ранее, чтобы не создавать дубликаты.

3. Чего приложение не делает

Приложение не читает содержимое файлов, не изменяет и не удаляет файлы, созданные людьми, не анализирует их содержание. Оно не передаёт данные Google-аккаунта третьим лицам, не использует их для рекламы, построения профилей и обучения моделей искусственного интеллекта, не продаёт их и не объединяет с данными из других источников.

Использование и передача приложением «tender» информации, полученной через программные интерфейсы Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

4. Хранение и защита

Приложение не ведёт собственной базы данных и не хранит содержимое обработанных файлов. Токен доступа к Google-аккаунту хранится на сервере Владельца в файле с ограниченными правами чтения, доступном только служебной учётной записи приложения; в исходный код и системы контроля версий он не попадает. Токен хранится до его отзыва или до прекращения использования приложения.

5. Отзыв доступа

Владелец аккаунта в любой момент может отозвать выданный приложению доступ на странице Сторонние приложения с доступом к аккаунту. После отзыва приложение теряет возможность обращаться к Диску; ранее созданные папки и загруженные файлы остаются у владельца аккаунта без изменений.
